## 🎬 How to Use (3 Ways)

### Way 1: Setup Wizard (First Login)
1. Login to the application
2. **Setup Wizard appears automatically**
3. Click **"Try Demo Mode"**
4. Start exploring immediately!

### Way 2: Direct Access
1. Login to the application
2. Go to **Database Connections** page
3. See "🎯 Demo Database (Sample Data)" already connected
4. Start using features right away!

### Way 3: Reset to Demo
1. Go to **Database Connections** page
2. Click **"Reset to Demo"** button (top-right)
3. Application reloads with fresh demo data
4. All sample data restored!

4. Test and save

1. Write queries against your data
2. Save and create APIs
3. Test and publish
